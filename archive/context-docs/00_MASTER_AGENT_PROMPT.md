## CORE RULES — NEVER BREAK THESE

### Code Quality
1. **No mock data in production code** — all data comes from API calls
2. **TypeScript strict mode** — no `any` types, all interfaces defined in `/src/types/`
3. **Every API call has error handling** — try/catch + user-facing error toast
4. **No hardcoded strings** — use constants files for status codes, labels, enums
5. **Responsive first** — every component works on mobile (375px) and desktop (1440px)

### Stitch Conversion Rules
6. **Stitch files are in `/stitch-screens/`** — treat them as design reference only
7. **Extract CSS variables** from Stitch files and move to `/src/styles/tokens.css`
8. **Convert HTML structures** to React JSX — preserve all class names and layout
9. **Replace static data** in Stitch HTML with real API-connected state
10. **Never delete Stitch files** — keep originals as reference

### Architecture
11. **API calls only through `/src/api/` layer** — never fetch directly in components
12. **Global state in Zustand** — auth, user, active job, notifications
13. **Server state in TanStack Query** — all API data, mutations, caching
14. **Forms with React Hook Form + Zod validation**
15. **All dates in IST** — store UTC in DB, display IST in UI

### Backend
16. **All routes protected by `authMiddleware`** except `/api/v1/auth/login`
17. **RBAC middleware on every route** — check role before processing
18. **Input validation with Zod on every POST/PATCH endpoint**
19. **Soft deletes** — never hard delete records, use `deleted_at` timestamp
20. **All monetary values** — DECIMAL(10,2) in DB, never float in JS (use string or integer paise)
